# 品种隐藏与多流程同时显示

2026-10-26 用户根据截图明确要求：三个品种可以隐藏，只要品种显示，其对应七步流程也完整显示。本轮调整视图及显示设置，不改变 Bias、Setup、方向权限和委托/持仓规则。

## 行为

- 每个品种卡有隐藏按钮；顶部可逐个恢复、显示全部。隐藏设置保存本地并包含在完整 JSON 备份。
- 隐藏卡片和对应流程面板，不清除工作状态。被隐藏品种有持仓/挂单时，顶部仍保留敞口提示。
- 支持全部隐藏与恢复。全部隐藏时停止活跃操作计时，不记录虚构的环节进入。
- 每个显示品种有自己的七步导航、当前任务、候选位置及事件入口；无需先选中再操作。七步均完整列出，当前环节仍突出唯一主要任务。
- 多品种在宽屏并列，窄屏纵向排列；只显示一个品种时使用较宽的原布局。
- 按钮按所在面板确定品种，危险确认绑定发起品种，入场备注按品种独立。导入/统计清空等全局确认不标记为单品种操作。
- 操作统计仅结算最近操作的一个品种；显示偏好不伪造市场事件，不复制多份点击和耗时。

## 数据兼容

工作区 v1 新增可选 hiddenSymbols 字段；旧数据缺少字段时默认显示全部。已有 workflows、execution、candidates 与 analytics 不迁移或清空。显示设置也随完整 JSON 导入/导出。无效的显示字段通过原有严格验证与备用/隔离恢复机制处理。engine.ts、analytics.ts、rules.ts 未更改业务逻辑。

## 本地验证

- 69 项自动化测试通过、0 失败；TypeScript 与 Vite 生产构建通过。
- 旧格式模拟备份经浏览器文件导入验证；GC 等待 PB、CL 观察交易位置、ES 持仓 + 剩余挂单，三个流程各含 7 个导航按钮，共 21 个。
- 隐藏 ES 后只剩两个面板和 14 步，顶部仍显示 ES 敞口；刷新后仍保持隐藏。全部隐藏后为 0 个面板，逐个恢复与显示全部均正常。
- GC 与 CL 同时进入入场检查，分别确认不同的原逻辑点；下载备份核对值各自独立，CONFIRM_POINT 的人工操作事件恰为 GC、CL 各 1 条。
- 同一份备份确认 ES.position=true、ES.order=pending，隐藏/恢复与其他面板操作未清除其敞口。
- GC 发起的确认弹窗标明 GC；确认后仅 GC 回到交易位置，CL 保持入场检查、ES 保持现场恢复。
- 1440px 桌面与 444px 窄屏下所有显示品种均有完整七步；窄屏 scrollWidth=clientWidth=444，未发现可见 P/R/U 编号或浏览器 error。
- 只读审查未发现明确可复现的 P1/P2 问题；审查未编辑文件或运行服务。
