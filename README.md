# Trading Decision SOP Dashboard V1

独立的交易决策流程导航看板，仅为人工确认的 SOP 路由辅助，不包含自动交易、行情获取或真实订单执行。

GitHub Pages 发布文件位于 `main` 分支根目录：`index.html`、`assets/` 和 `.nojekyll`。

打开页面：https://xhb-d.github.io/trading-decision-sop/

部署设置：Settings → Pages → Deploy from a branch → main → /(root)。

隐私：浏览器 localStorage 存储用户数据，不会自动上传 GitHub。更换浏览器请使用 JSON 导入/导出。当前仓库仅包含编译后的静态网站，不包含原始 TypeScript 源码。
